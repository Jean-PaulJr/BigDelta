# Example files

`Framing-P01.pdf` and `Framing-P02.pdf` show a relocated opening. Create a project, upload P01, then use **+ Revision** on that document to upload P02. This allows you to test the history and drawing-comparison workflow.

`example-package.pdf` is a compiled draft with a cover, linked contents, section divider, current drawing, assumptions/code register, and continuous page numbering. `example-manifest.json` records which revision was used. IDs and internal storage paths in that manifest belong to the demonstration workspace; these files do not seed your new application's database.

These are illustrations only, not engineering calculations or construction documents.
